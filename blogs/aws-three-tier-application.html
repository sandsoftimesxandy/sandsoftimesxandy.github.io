Three-tier web application on AWS that involves setting up different layers for the application. First is the Presentation-Tier then is Application-Tier, and the last is Data Tier. We've used the VPC and Sub-nets for reliable access. Also we added Load-Balancer for Handling-High-Traffic in order to provide Reliability. Also the aws auto-scaling feature is used in this project by which our system can scale as per need.
