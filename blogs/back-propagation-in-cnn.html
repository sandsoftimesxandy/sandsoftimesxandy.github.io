Back propagation is the heart of Machine Learning. Machine learning is all about creating virtual machines, guiding them and correcting them. Thus we get the machines which are aware of what is actually happening. This correcting portion is done by backpropagation. We correct the machine and our message is propagated back to the brain aka neurons of the machine add this remember this corrected knowledge. Thus by the end of our training machine (virtually created machine) know very well how to answer similar problems but unknown ones.

In ANN (Artificial Neural Network) the backpropagation is carried out by the propagation of error back through the complete network of neurons but in CNN (Convolution Neural Network) there are filters. "Volla". So what now?. Actually things are pretty easy or you can say more reliable here. We've weight filters although the classification layer will still be ANN layer taking flatten input blah blah but for now forget about that and consider we have just the filters only, also drop the pooling/normalizations as well for the time being. The error is propagated back through the filters, thus the filter weights change accordingly. At the end, our machine have the correct knowledge to classify aka solve the incomming unknown but similar problem. That's how the backpropagation works in CNN's.
