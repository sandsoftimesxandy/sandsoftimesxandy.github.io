Recurrent Neural Network is a specific type of Neural Network that not only the consider the current input and predict the output instead it maintains the record of past experience by keeping a hidden state. This hidden state is passed along with the next input to the recurrent unit. There will be two weights involve, once with the input to the recurrent unit and second the weight with the hidden state comming from previous timestamp which will both contribute in predicting the output. Similarly the back propagation in RNNs is a bit different from the ordinary neural network. Here "Back-Propagation-Through-Time(BPTT)" occur. You can look into it in more detail from the excellent blog post of "geeksandgeeks".
